# Raisin Variety Classification

This notebook trains a Logistic Regression model to classify Raisin varieties.

Steps included:
1. Load and explore Raisin dataset (.xlsx format)
2. Preprocess data and standardize features
3. Split dataset 80:20 into training and test sets
4. Train Logistic Regression with 5-Fold Cross-Validation
5. Evaluate on test set (accuracy ≥ 81%)
6. Detailed classification report per class

Dependencies:
- Python 3.x
- pandas
- scikit-learn
- openpyxl

Dataset: Please download from [Kaggle Raisin Dataset](https://www.kaggle.com/datasets/muratkokludataset/raisin-dataset)
